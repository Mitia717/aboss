# Прототип: Alfa-boss Sales Intelligence

Интерактивный HTML-прототип для **руководителя клиентских менеджеров**.

## Как открыть

Откройте в браузере файл:

`prototype/index.html`

## Что нового (v2)

- **Тултипы** на KPI, колонках и этапах воронки (наведите курсор)
- **Мультивыбор** дивизионов / регионов / команд / продуктов
- Кнопка **«Все дивизионы (total)»** — свод по всей сети
- **Конверсии** УКП → акцепт / заявка / сделка + сравнение КМ
- **Антирейтинг качества** — много отправок при низкой конверсии в акцепт
- Вкладка **Прогноз** — из пайплайна статусов УКП и сценария «закрыть доступно»
- Режим **Продуктовый desk** — обзор продукта, дивизионы, качество сети

## Режимы

| Режим | Для кого |
|-------|----------|
| Сеть (КМ) | Руководитель клиентских менеджеров |
| Продуктовый desk | Руководитель / аналитик продуктовой фабрики |

По умолчанию: МОСКОВСКИЙ · Москва Упр 1 · Отд 1.
